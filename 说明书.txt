听谱 · NoteMender 2.5.0-demo.7 使用说明书
============================================

一、这个 Demo 能做什么

听谱把音频转换成一条可编辑的主旋律简谱。识别结果是供人听审的初稿，不是准确乐谱的保证。你可以边听原曲边看谱、调整单音的音高和起止位置、框选批量修改、管理歌曲区块，最后导出工程、简谱图、MIDI 或合成音频。识别在本机运行。

二、系统准备与启动

1. 本程序的桌面启动器和组件安装脚本面向 Windows x64。源码下载需要 Node.js 22 或更新版本。已有 Node.js 时可双击“Start-NoteMender.cmd”；从源码重新构建可在项目目录运行 npm ci、npm run build、npm start。
2. 启动器会打开终端显示的本机地址，只监听 127.0.0.1。浏览器未自动打开时，复制地址到浏览器。再次启动同一目录会复用服务。移动目录后地址可能变化，迁移前请先保存工程 JSON。
3. 按需下载版已附 Node.js、Python 基础解释器和浏览器识别模型；编辑和浏览器识别可直接使用。分轨、歌词及显卡等功能从“Download-Components.cmd”选择安装，已就绪组件会复用。具体见 docs/组件说明.md。
4. 标准离线版已附 CPU 音频环境、四／六轨模型及 Qwen 歌词模型。下载全部离线分片、offline-manifest.json、Extract-NoteMender.ps1 和 Extract-NoteMender.cmd，放在同一目录，运行解压 CMD 后启动。显卡离线扩展使用 gpu-manifest.json 和 Extract-GPU-Addon.cmd，解压后运行 Install-GPU-Addon.cmd 并输入标准版程序目录。显卡组件需要相容的 NVIDIA 驱动，安装后重启程序。请保留程序目录结构。
5. 关闭服务可在任务管理器结束对应 node 进程。关闭浏览器标签页不会自动停止服务。

三、最快的首次试用

1. 启动后导入 examples 文件夹中的“C大调音阶-120BPM.wav”。
2. 为缩短第一次试用时间，可取消“本机分离人声与器乐，逐段生成”，并在 BPM 输入框填 120。完整歌曲可保留分轨勾选。
3. 点击“生成简谱”。完成后出现候选窗口。你可以直接点击“放入工作区修改”，试听不是必经步骤。
4. 在简谱工作区点击音符，右侧栏会显示可修改的音高、起始拍和持续拍数。点击播放后，对照原音与谱面。

四、完整歌曲与人声分离

歌曲有伴奏时，安装 Demucs 分轨组件后可以分轨：程序优先从人声轨识别唱段，并从器乐轨寻找前奏、间奏和尾奏。分轨在本机运行，整曲处理可能持续数分钟。

安装完成后，左侧应显示“本地 Demucs 已就绪”。组件未安装时可以取消分轨，先从原曲混音生成；组件安装不会替你校正识别结果。

导入常见音频格式时，浏览器会优先直接解码；浏览器不支持的文件需要上述 Python 解码环境。音频上限为 120 MB、约 10 分钟。处理整曲时，分轨和识别可能持续数分钟。

五、从歌曲生成并核对简谱

1. 导入歌曲。默认“自动按段选择”会在有人声、清晰单音和密集器乐之间选择识别策略；也可以指定 Basic Pitch 或 Pitchy 作对照。可填写起止秒数，仅处理一段。
2. 默认可保留分轨勾选；想缩短处理时间时可取消。可调音域与节奏精度。若自动测速不可用，会按当前 BPM 生成候选并提示；可随后调整 BPM 与原音对齐点。
3. 点击“生成简谱”。生成期间请保持页面打开。新歌导入和生成时，旧谱会暂时收起，不会立即被覆盖。
4. 候选窗口显示各段使用的音轨和策略，可切换同段不同识别结果，也可试听同位置的原曲、旧谱和候选谱。点击“收起”只隐藏窗口，页面顶部“继续查看候选”可恢复；刷新页面后候选谱与已选备选也能恢复。生成时原音与分轨已保存在本机资源目录，工程会保存引用；资源缺失时重新关联原音。
5. 只有点击“放入工作区修改”才会采用候选。原谱先进入浏览器备份。采用后所有机器音符仍是“待校对”，请逐段听审。新生成音符均待校对；算法疑点收在分析详情中，不能直接视为错误结论。
6. 发现一段难改时，可在“歌曲区块”波形上拖出范围，精确设定起止秒数，再对该段执行本机重识别。手动区块不会暗中改变下一次整曲自动划段。

六、边听边修改

“聆听与对照”显示原音波形。播放时谱面只高亮当前音，不强制滚动；波形放大后，视窗在光标接近边缘时整段切换。波形显示声音强弱，不是音高曲线。点击波形可定位；后退/前进 3 秒、循环和播放位置按钮用于反复核对。

简谱中的色块长度代表音符持续拍数，数字不会随色块拉伸。拖色块中间可移动音符，拖左右边缘可调整起止。很短的音符可能显示为细标记；点击后在右侧查看完整音高，或把“横向缩放”滑条拉大。每行拍数可在 1–16 拍之间细调，行高不变。点击音符后在右侧编辑栏输入精确数值；点击空白处的“+”可插入新音符。按 Esc 可取消选择。

打开“框选模式”可跨行圈选音符，右侧提供批量删除、升降半音/八度及标为已校对。选中后可复制，再指定空白拍位粘贴；也可选择明确覆盖目标范围。单个音符还能在指定拍位切割成两段。撤销/重做可恢复编辑动作。Ctrl+C、Ctrl+V、Ctrl+Z 和 Ctrl+Y 可用于常见操作；空格控制播放。鼠标选中不会在开始播放后一直遮住当前播放高亮。

“批量输入音符（可选）”适合一次录入音符串。例如：1:1 2:0.5 #4:0.5 0:1。数字 1–7 是音高，0 是休止；冒号后的数字为拍数；#、b 表示升降半音，单引号和逗号表示高低八度。最细输入精度为 0.0625 拍。可先自由写入，不要求填满小节，最后再查看分小节预览。

“1=”只改变记谱基准；“转调音高”或右侧“整体升音/降音”会改变实际 MIDI 音高。超过可用音域的批量修改会被拒绝。

七、区块、时间对齐与 MIDI

“歌曲区块”可在原曲波形上创建、改名、改变边界、定位、单段重识别或删除。删除区块只移除区块标记及关联备选，不删除正式音符或原音。区块固定在原曲秒数；调整“原曲时间对齐点”后仍对应原来那段音频。对齐点用于修正长曲中谱面与原曲的漂移。

“导入 MIDI”可选择一条主唱或主奏轨，先作为单声部候选预览，再决定是否放入工作区。MIDI 来源和音准仍需人工检查；单纯把当前识别结果转存成 MIDI，不会使识别更准确。

八、保存、恢复与导出

点击“保存工程”（或 Ctrl+S）可自定义保存名称，默认使用曲名，自动添加 .json。程序会记住此曲上次使用的名称；打开已有工程后也会沿用文件名称。保存名称不改变谱面曲名。文件保存在 exports 文件夹，同时下载到浏览器的下载目录。同名文件自动添加 (2)、(3)，保留之前的版本；不能用于文件名的字符会替换为下划线，保存前可查看实际名称。

程序会将当前工程自动存到这个浏览器的当前本机地址。请定期点击顶部“保存工程”，把 JSON 文件另存到可靠位置。候选暂存、撤销历史和浏览器备份不能代替独立 JSON 文件。更换浏览器、移动解压目录或清除站点数据可能让原地址下的自动保存不可见。

“恢复备份”可找回采用候选前的工程；“打开工程”可导入此前保存的 JSON。JSON 不内嵌原音，保存本机音频资源引用；本机资源仍在时可恢复试听。换设备时一并复制 runtime/audio-resources，或重新关联原音。工程导入和保存统一上限 32 MB，超过 5 MB 的工程也能打开。可导出 JSON、SVG、MIDI、合成 WAV，也可通过浏览器打印为 PDF。导出文件会下载，同时保存在本程序目录的 exports 文件夹。

九、常见问题

· 启动提示离线包不完整：确认整个 ZIP 已解压，且 runtime/node/node.exe、runtime/python/python.exe 与模型文件仍在原目录中。
· 浏览器没有自动打开：查看启动窗口的 127.0.0.1 地址，复制到浏览器。不要只双击 public/index.html。
· 显示“本机 Demucs 未就绪”：检查本机环境和模型是否齐全，或取消分轨后试用；环境修复后刷新状态。
· 自动测速度失败：手动填写 BPM 再点击生成；无法确定时先用估计值，之后借助原曲时间对齐点校准。
· 音频导入失败：尝试 WAV 或 MP3；其他格式需 Python 解码环境。检查文件是否损坏、超过 120 MB 或 10 分钟。
· 生成结果漏音/错音：调整音域、换 Basic Pitch/Pitchy、给问题片段单独重识别，并手动校对。复杂伴奏与合唱不能指望自动生成准确谱。
· 候选窗口误关：页面顶部点“继续查看候选”；已采用的结果在工作区，旧谱可到“恢复备份”查找。
· 原曲试听按钮变灰：工程引用的音频资源可能缺失，重新关联原音即可。
· 启动后看到别的工程：浏览器会恢复此地址先前的自动保存；点击“打开工程”载入自己的 JSON，或“新建空白乐谱”。不同解压目录的启动器会分别启动服务。

第三方组件许可见 licenses 文件夹。


十、识别方案与悬浮说明

把鼠标放在按钮、参数或下拉框上，可查看用途和注意事项。识别链路下方还会显示当前方案的简短说明。顶部“使用说明”始终可打开本说明书，支持按功能、模型或快捷键搜索，也可下载 TXT。

· 本机扒谱方式：自动按段选择在人声、清晰单音和密集器乐之间选策略；Basic Pitch 是多音符神经网络，再筛选主旋律；Pitchy 使用 McLeod 单音音高检测算法，适合哼唱或清晰独奏。
· 现版默认基线：沿用当前识别后的筛选、合并与量化规则，适合日常使用及结果对比。
· 改进规则：实验性的重复同音保护、短音保留、自适应能量、候选融合和连续旋律筛选。是否改善需要实际听审。
· 改进规则 + pYIN：额外加入概率单音音高跟踪，适合清晰人声、独奏的音准与八度对比，处理更久。
· 改进规则 + CREPE：额外加入 torchcrepe 的 CREPE tiny 神经网络单音跟踪，需可选组件，适合音准和八度对比，不做歌词转写。
· ROSVOT 演唱分音与歌词参考：可选额外候选，使用演唱分音、RMVPE 音高与字词边界参考；歌词条件可能改变分音，须试听后决定是否采用。
· 歌词自动对应：Qwen 识别文字并按原音对齐，再对应音符。默认保留原声学分音，边界调整是备选。
· 高性能模式：使用已通过一致性验证的后端，不减少备选。设备选择按各阶段实际能力生效，无法使用时明确显示回退。
· 规则对照：开发比较工具，每次只关闭一组实验规则；不需要日常调整。

十一、歌词与原音时间的修改

1. 顶部打开“歌词对照”，默认按已划分的人声区段识别，无需输入起止时间；指定语言、音轨和手动范围在高级设置。
2. Qwen 转写、时间对齐分阶段运行并显示进度。先校正文字，再用“对齐选句”定位原音；单选会使用所在句，Ctrl 多选可指定文字范围。自动结果先预览，确认后采用。
3. 歌词条显示在音符下方，以自己的原曲秒数为准。点击改字或精确起止，拖动移动，拖左右边缘调长短。错误的音符关联不会自动把文字拖到该音符位置。
4. 关联音符：先选择歌词，点“选择对应音符”，再点击或 Ctrl 点击谱面音符，最后“关联所选音符”。可一字多音或多字一音。“同时改歌词时间为所选音符起止”默认关闭，只有主动勾选才跟随音符改时间。
5. Ctrl 点击自由多选歌词，Shift 点击选连续歌词。复制、剪切、粘贴、删除支持 Ctrl+C / X / V 和 Delete；点击谱面空白指定目标，也可输入粘贴起点的原曲秒数。目标已有文字时需明确勾选“覆盖目标歌词”。
6. 粘贴保留文字的持续时间和相对间隔，使用新 ID，并按目标位置重新对应；不会改变音符。批量移动可输入正负秒数，或拖动所选条整体移动。剪切、粘贴、移动和删除可一次撤销。
7. 未定位文字不会被平均摊到音符上；先手工指定正确时间，再复制其时间条。文字框内的 Ctrl+C / X / V 使用普通文本操作。
8. 右侧保留手工逐音填字、多个音共用文字、批量查找替换、解除关联与字词拆分合并。修改文字和原音时间不必重新扒谱。
9. “重新对应本句”按现有时间重新匹配；“按歌词重新分音本句”会调用局部分音并产生辅助候选，确认后才替换。拖腔允许一字多音，不能为了配字强制切音。

十二、选择与常用快捷键

普通点击单选；Ctrl 点击追加或取消非相邻音符／歌词；Shift 点击选连续范围。空白处拖动可框选，开启框选模式后可从音符上拖出矩形；Ctrl 框选追加，Shift 框选减选。点击空白同时取消选择并指定插入或粘贴位置。

Ctrl+C 复制；Ctrl+X 剪切；Ctrl+V 粘贴；Delete 删除；Ctrl+Z 撤销；Ctrl+Y 或 Ctrl+Shift+Z 重做；Ctrl+S 保存工程；Esc 清除选择；空格播放／暂停；S 在播放位置切开音符。

音符合并仅用于连续范围；不同音高会询问保留哪个音高，也可输入新的 MIDI 音高。有空拍时须主动选择填入空拍，夹有未选音符时拒绝合并。自由多选可批量替换音高、升降、复制或删除。

“时值检查与批量处理”按原音秒数定位短音／长音，选中音后仍保持可用。可选择全部结果、合并相邻同音短片段，或在播放位置切开长音；只按时长筛选不能证明音符错误。

十五、按歌词切分长音

如果一句唱得很快，却被识别成一个长音，而下方歌词已有正确的逐字或逐词时间：先采用歌词对应，点击长音（Ctrl 多选或框选可选择多个），再点顶部“按歌词切分”或右侧“按歌词切分此音”。查看预览中的字词、音高、原音起点和时长后，确认切分。取消预览不会修改谱子。

切分使用每个后续字词的原音起点，按当前对齐关系换算为最近的 1/16 拍；保留原长音的起止与音高，不重新运行识别模型。切出的音均标为待校对，可慢放逐字检查并改音高。歌词本身的原音时间不变，对应会更新到切出的音；Ctrl+Z 可一次恢复音符、歌词与选择。

只有带独立时间的字词才可确定边界。未定位的文字、单条整句文字不会被平均分配；过近或时间相同的边界会提示并跳过，文字保留。正常拖腔的一字多音无须使用此工具。

十六、编辑快捷键与开关

谱面工具条的“快捷键：开 / 关”可打开完整按键表与总开关，状态保存在本机；Ctrl+Alt+K 可随时切换（关闭后仍可用）。在文字输入框、参数输入框或弹窗中不会执行编辑快捷键。普通的输入、Tab、Enter 及 Ctrl/Shift 鼠标多选仍可用；关闭快捷键后，其他按键由浏览器按默认方式处理。

播放：空格播放/暂停；Alt+左右方向键退/进3秒；- 或 = 减/加0.05倍试听速度；R循环所选音符。
选择：左右方向键选前/后音；Ctrl+A全选音符，已选择歌词时全选歌词；F开关框选；Esc清除选择。
改谱：上下方向键升/降半音，Shift+上下方向键升/降八度；[ 或 ] 减/加单音1/16拍；S播放处切开，Shift+S在所选单音中点切开；M合并；L按歌词切分；V标为已校对；I打开插入工具。
通用：Ctrl+C/X/V复制/剪切/粘贴，Delete删除，Ctrl+Z撤销，Ctrl+Y或Ctrl+Shift+Z重做，Ctrl+S打开保存命名；?（Shift+/）打开快捷键面板。复制、切割、合并、删除会根据选择操作音符或歌词，音高和时长键仅用于音符。

持续按住方向键或时长键可连续调整；切割、合并、删除、保存和开关不会因长按连续执行。

十七、音符与歌词的联动编辑

谱面、歌词面板和点字词后的修改框都有“联动音符与歌词”开关，它们共用同一设置，默认关闭；确认对应准确后可手动开启，选择保存在本机。对应关系不仅用于显示：移动或拉伸已关联的音符，会一起移动或按比例拉伸对应歌词；修改歌词起止也会联动对应音符。数值输入、拖动和歌词批量移动均支持。

一字多音、多字一音以及彼此相连的对应会构成一个联动组。操作前查看“当前对应组：几音、几个字词”；整个组一起移动或按比例拉伸，其余音符与歌词不变。音高不随联动变化，对应ID不变。拖动时显示整组预览，松手后应用；如果与组外音符重叠、超出原音或压得过短，整组拒绝修改，可关掉联动后单独校准。

修改起止仍受1/16拍编辑网格限制，原音秒数与谱面拍位按现有对齐关系换算。取消拖动不修改，应用后可一次撤销并恢复两边。歌词识别预览未采用时不联动正式音符；先采用对应，再启用联动编辑。联动不触发模型识别，也不自动改音高。
