NoteMender 使用说明书
============================================
顶部语言选择可切换简体中文、English 和日本語，偏好保存在当前浏览器。切换不会修改工程、音高、歌词或文件名。英文界面的原始诊断消息与版本说明正文可能保留原文。


一、NoteMender 能做什么

顶部导航正中是“简谱预览”。“工程”中可打开、保存和恢复备份，“帮助与设置”中可管理组件、查看说明和版本、打开 GitHub 或反馈；有更新时收起菜单也看得见。右侧用“编辑工具”和“歌词对照”切换。谱面工具条把选择及剪贴板和音符编辑分组，拍号在调号旁。
新开工程或导入新音频时，主工作区默认使用“合成旋律”；没有谱音时可手动切换“原始音频”。缩放波形后，播放时光标离开窗口会自动跟随。暂停时可用箭头或滑块浏览，点击“播放位置”回到光标。


NoteMender 把音频转换成一条可编辑的主旋律简谱。识别结果是供人听审的初稿，不是准确乐谱的保证。你可以边听原曲边看谱、调整单音的音高和起止位置、框选批量修改、管理歌曲区块，最后导出工程、简谱图、MIDI 或合成音频。识别在本机运行。

二、系统准备与启动

1. 本程序的桌面启动器和组件安装脚本面向 Windows x64。源码下载需要 Node.js 22 或更新版本。已有 Node.js 时可双击“Start-NoteMender.cmd”；从源码重新构建可在项目目录运行 npm ci、npm run build、npm start。
2. 启动器会打开终端显示的本机地址，只监听 127.0.0.1。浏览器未自动打开时，复制地址到浏览器。再次启动同一目录会复用服务。移动目录后地址可能变化，迁移前请先保存工程 JSON。
3. 推荐基础离线版（约 0.81 GB），已附 CPU 音频环境与四／六轨模型；解压即可扒谱、分轨、试听和编辑。轻量版约 65 MB，附 Node.js、Python 基础解释器和浏览器模型，其余功能按需安装。
4. 首次启动显示组件安装界面，先询问是否扫描已有环境。允许后检查常用环境和模型缓存，也可指定已有程序目录；发现兼容组件可“校验并复用”。不想扫描可选“暂不扫描”，也可勾选组件后直接安装；未经允许不会扫描外部环境。歌词、显卡和 ROSVOT 都不默认勾选；选择需要的组件后安装，完成后点击“进入工作台”。以后在顶部“组件管理”或 Manage-Components.cmd 随时添加。显示安装位置、磁盘空间、阶段进度和下载详情，支持取消及重试续传。组件缺失时对应自动按钮变灰，悬停说明用途和需要下载。手工歌词编辑仍可用。
5. 关闭服务可在任务管理器结束对应 node 进程。关闭浏览器标签页不会自动停止服务。

三、最快的首次试用

1. 启动后导入 examples 文件夹中的“C大调音阶-120BPM.wav”。
2. 为缩短第一次试用时间，可取消“本机分离人声与器乐，逐段生成”。完整歌曲可保留分轨勾选。
3. 点击“生成简谱”。完成后出现候选窗口。你可以直接点击“放入工作区修改”，试听不是必经步骤。
4. 在简谱工作区点击音符，右侧栏会显示可修改的音高、起始拍和持续拍数。点击播放后，对照原音与谱面。

四、完整歌曲与人声分离

歌曲有伴奏时，安装 Demucs 分轨组件后可以分轨：程序优先从人声轨识别唱段，并从器乐轨寻找前奏、间奏和尾奏。分轨在本机运行，整曲处理可能持续数分钟。

安装完成后，左侧应显示“本地 Demucs 已就绪”。组件未安装时可以取消分轨，先从原曲混音生成；组件安装不会替你校正识别结果。

导入常见音频格式时，浏览器会优先直接解码；浏览器不支持的文件需要上述 Python 解码环境。音频上限为 120 MB、约 10 分钟。处理整曲时，分轨和识别可能持续数分钟。

五、从歌曲生成并核对简谱

1. 导入歌曲。默认“自动按段选择”会在有人声、清晰单音和密集器乐之间选择识别策略；也可以指定 Basic Pitch 作对照。可填写起止秒数，仅处理一段。
2. 默认可保留分轨勾选；想缩短处理时间时可取消。可调音域与节奏精度。程序会从原曲自动估计速度。估计不可用时，候选暂用工程速度，可通过原曲时间对齐点校准。
3. 点击“生成简谱”。生成期间请保持页面打开。新歌导入和生成时，旧谱会暂时收起，不会立即被覆盖。
4. 候选窗口显示各段使用的音轨和策略，可切换同段不同识别结果，也可试听同位置的原曲、旧谱和候选谱。点击“收起”只隐藏窗口，页面顶部“继续查看候选”可恢复；刷新页面后候选谱与已选备选也能恢复。生成时原音与分轨已保存在本机资源目录，工程会保存引用；资源缺失时重新关联原音。
5. 点击“放入工作区修改”会先自动备份原谱，再以完整候选覆盖工作区，不再询问采用范围，不受当前试听画面限制；候选自己的调号、速度、时间映射和歌词一同采用。采用后所有机器音符仍是“待校对”，请逐段听审。新生成音符均待校对；算法疑点收在分析详情中，不能直接视为错误结论。
6. 发现一段难改时，可在“歌曲区块”波形上拖出范围，精确设定起止秒数，再对该段执行本机重识别。手动区块不会暗中改变下一次整曲自动划段。

六、边听边修改

“聆听与对照”显示原音波形，波形正上方是当前播放时间和总时长。主试听可选“合成旋律”或“原始音频”，默认是合成旋律。播放时谱面只高亮当前音，不强制滚动；波形放大后，视窗在光标接近边缘时整段切换。波形显示声音强弱，不是音高曲线。点击波形可定位；后退/前进 3 秒、循环和播放位置按钮用于反复核对。

简谱中的色块长度代表音符持续拍数，数字不会随色块拉伸。拖色块中间可移动音符，拖左右边缘可调整起止。很短的音符可能显示为细标记；点击后在右侧查看完整音高，或把“横向缩放”滑条拉大。每行拍数可在 1–16 拍之间细调，行高不变。点击音符后在右侧编辑栏输入精确数值；点击空白处的“+”可插入新音符。按 Esc 可取消选择。

开启工具条“框选”后，拖动即可跨行框选音符与歌词；右侧提供批量删除、升降半音/八度及标为已校对。选中后可复制，再指定空白拍位粘贴；也可选择明确覆盖目标范围。单个音符还能在指定拍位切割成两段。撤销/重做可恢复编辑动作。Ctrl+C、Ctrl+V、Ctrl+Z 和 Ctrl+Y 可用于常见操作；空格控制播放。鼠标选中不会在开始播放后一直遮住当前播放高亮。

“粘贴”旁的“片段剪贴板”可存最多 20 个片段。选中一个音或一组音后点“存入剪贴板”，再按需命名、试听或切换片段。选中的片段会在下方显示简谱色块缩略图，长片段可横向滚动查看。要用正确的一句修另一句，先选中目标，再点“仅贴音高”。两边有音高的音符数必须相同，按时间顺序对应，目标的节奏、歌词和记号照旧。“整段粘贴”用指定拍位，保留来源时值和间隔，只在一起选中歌词时带入对应的歌词。“设为当前复制内容”后也可用 Ctrl+V。简谱、五线谱及同一页面打开的工程共用这些片段，刷新或关闭页面后清空。

右侧曲名下方的“连续写音符”可点数字排好队列，一次写入；其中“高级：文本输入”仍适合用原语法录入音符串。例如：1:1 2:0.5 #4:0.5 0:1。数字 1–7 是音高，0 是休止；冒号后的数字为拍数；#、b 表示升降半音，单引号和逗号表示高低八度。最细输入精度为 0.0625 拍。可先自由写入，不要求填满小节。排版时打开顶部“简谱预览”。

“1=”只改变记谱基准；“转调音高”或右侧“整体升音/降音”会改变实际 MIDI 音高。超过可用音域的批量修改会被拒绝。

七、区块、时间对齐与 MIDI

“歌曲区块”默认显示整首歌曲和全部区块，视图可切换为20／40／80／160秒局部放大，再选“整首歌曲”返回总览。点击区块列表会定位；局部视图自动切到该段，较长区块自动扩大视野。切换视图只改变显示，不会改段落起止。窗口边缘裁切处不显示调整拖柄，只有区块真实起止位置可拖动。“补齐谱面前奏空白”仅补齐原音开头的谱面空白，与区块视图无关。
“歌曲区块”可在原曲波形上创建、改名、改变边界、定位、单段重识别或删除。删除区块只移除区块标记及关联备选，不删除正式音符或原音。区块固定在原曲秒数；调整“原曲时间对齐点”后仍对应原来那段音频。对齐点用于修正长曲中谱面与原曲的漂移。

“导入 MIDI”可选择一条主唱或主奏轨，先作为单声部候选预览，再决定是否放入工作区。MIDI 来源和音准仍需人工检查；单纯把当前识别结果转存成 MIDI，不会使识别更准确。

八、保存、恢复与导出

点击“保存工程”（或 Ctrl+S）可自定义保存名称，默认使用曲名，自动添加 .json。程序会记住此曲上次使用的名称；打开已有工程后也会沿用文件名称。保存名称不改变谱面曲名。文件保存在 exports 文件夹，同时下载到浏览器的下载目录。同名文件自动添加 (2)、(3)，保留之前的版本；不能用于文件名的字符会替换为下划线，保存前可查看实际名称。

程序会将当前工程自动存到这个浏览器的当前本机地址。请定期点击顶部“保存工程”，把 JSON 文件另存到可靠位置。候选暂存、撤销历史和浏览器备份不能代替独立 JSON 文件。更换浏览器、移动解压目录或清除站点数据可能让原地址下的自动保存不可见。

“恢复备份”可找回采用候选前的工程；“打开工程”可导入此前保存的 JSON。JSON 不内嵌原音，保存本机音频资源引用；本机资源仍在时可恢复试听。换设备时一并复制 runtime/audio-resources，或重新关联原音。工程导入和保存统一上限 32 MB，超过 5 MB 的工程也能打开。可导出 JSON、SVG、MIDI、合成 WAV，也可通过浏览器打印为 PDF。导出文件会下载，同时保存在本程序目录的 exports 文件夹。

九、常见问题

· 启动提示离线包不完整：确认整个 ZIP 已解压，且 runtime/node/node.exe、runtime/python/python.exe 与模型文件仍在原目录中。
· 浏览器没有自动打开：查看启动窗口的 127.0.0.1 地址，复制到浏览器。不要只双击 public/index.html。
· 显示“本机 Demucs 未就绪”：检查本机环境和模型是否齐全，或取消分轨后试用；环境修复后刷新状态。
· 自动测速度失败：候选暂用工程速度。若合成旋律和原曲错开，可用“原曲时间对齐点”校准。
· 音频导入失败：尝试 WAV 或 MP3；其他格式需 Python 解码环境。检查文件是否损坏、超过 120 MB 或 10 分钟。
· 生成结果漏音/错音：调整音域、比较 Basic Pitch 与已安装的可选识别方案、给问题片段单独重识别，并手动校对。复杂伴奏与合唱不能指望自动生成准确谱。
· 候选窗口误关：页面顶部点“继续查看候选”；已采用的结果在工作区；成功采用不会显示收起提示，旧谱可到“恢复备份”查找。
· 原曲试听按钮变灰：工程引用的音频资源可能缺失，重新关联原音即可。
· 启动后看到别的工程：浏览器会恢复此地址先前的自动保存；点击“打开工程”载入自己的 JSON，或“新建空白乐谱”。不同解压目录的启动器会分别启动服务。

第三方组件许可见 licenses 文件夹。


十、识别方案与悬浮说明

把鼠标放在按钮、参数或下拉框上，可查看用途和注意事项。顶部“帮助与设置”中的“使用说明”始终可打开本说明书，支持按功能、模型或快捷键搜索，也可下载 TXT。

· 本机扒谱方式：自动按段选择在人声、清晰单音和密集器乐之间选策略；Basic Pitch 是多音符神经网络，再筛选主旋律。Pitchy 已移除，不再参与自动识别或补漏；旧工程中的历史候选保留。
· 现版默认基线：沿用当前识别后的筛选、合并与量化规则，适合日常使用及结果对比。
· 改进规则：实验性的重复同音保护、短音保留、自适应能量、候选融合和连续旋律筛选。是否改善需要实际听审。
· 改进规则 + pYIN：额外加入概率单音音高跟踪，适合清晰人声、独奏的音准与八度对比，处理更久。
· 改进规则 + CREPE：额外加入 torchcrepe 的 CREPE tiny 神经网络单音跟踪，需可选组件，适合音准和八度对比，不做歌词转写。
· ROSVOT 演唱分音与歌词参考：可选额外候选，使用演唱分音、RMVPE 音高与字词边界参考；歌词条件可能改变分音，须试听后决定是否采用。
· 生成时附加歌词（Qwen，可选）：默认关闭，勾选才运行文字识别与对齐；关闭时只生成声学谱，之后仍可在“歌词对照”中主动识别歌词。开启后，Qwen 识别文字并按原音对齐，再对应音符。默认保留原声学分音，边界调整是备选。
· 高性能模式：使用已通过一致性验证的后端，不减少备选。设备选择按各阶段实际能力生效，无法使用时明确显示回退。
· 规则对照：开发比较工具，每次只关闭一组实验规则；不需要日常调整。

十一、歌词与原音时间的修改

1. 从右侧打开“歌词对照”，默认按已划分的人声区段识别，无需输入起止时间；指定语言、音轨和手动范围在高级设置。
在「音频与识别」附加歌词前，或在「歌词对照」识别前，可选「歌词语言」。知道是日语时选「日语」，不确定可选「自动判断」。设置供两个入口共用。已有日语歌词时，可展开「日语罗马音」查看本地词典给出的读音。专名和歌曲中的特殊读法请对照原音。

2. Qwen 转写、时间对齐分阶段运行并显示进度。先校正文字，再用“对齐选句”定位原音；单选会使用所在句，Ctrl 多选可指定文字范围。自动结果先预览，确认后采用。
导入已有歌词：打开 TXT、LRC、SRT 或 WebVTT，也可以粘贴内容。点“预览导入歌词”核对原曲秒数，再采用。SRT 和普通字幕按句保留起止时间，带行内时间戳的 WebVTT 或增强 LRC 可细到字词。增强 LRC 末项缺少结束时刻时，补填原曲秒数。建议使用 UTF-8。
3. 歌词条显示在音符下方，以自己的原曲秒数为准。点击改字或精确起止，拖动移动，拖左右边缘调长短。错误的音符关联不会自动把文字拖到该音符位置。
4. 关联音符：先选择歌词，点“选择对应音符”，再点击或 Ctrl 点击谱面音符，最后“关联所选音符”。可一字多音或多字一音。“同时改歌词时间为所选音符起止”默认关闭，只有主动勾选才跟随音符改时间。
5. Ctrl 点击自由多选歌词，Shift 点击选连续歌词。复制、剪切、粘贴、删除支持 Ctrl+C / X / V 和 Delete；点击谱面空白指定目标，也可输入粘贴起点的原曲秒数。目标已有文字时需明确勾选“覆盖目标歌词”。
6. 粘贴保留文字的持续时间和相对间隔，使用新 ID，并按目标位置重新对应；不会改变音符。批量移动可输入正负秒数，或拖动所选条整体移动。剪切、粘贴、移动和删除可一次撤销。
7. 未定位文字不会被平均摊到音符上；先手工指定正确时间，再复制其时间条。文字框内的 Ctrl+C / X / V 使用普通文本操作。
8. 右侧保留手工逐音填字、多个音共用文字、批量查找替换、解除关联与字词拆分合并。修改文字和原音时间不必重新扒谱。
9. “重新对应本句”按现有时间重新匹配；“按歌词重新分音本句”会调用局部分音并产生辅助候选，确认后才替换。拖腔允许一字多音，不能为了配字强制切音。

十二、选择与常用快捷键

普通点击单选；Ctrl 点击追加或取消非相邻音符／歌词；Shift 点击选连续范围。工具条“框选：开”时，从音符、歌词或空白处拖动可跨行框选音符与歌词；Ctrl 框选追加，Shift 框选减选。框选按音符和字词 ID 去重，跨行的同一块只计一次。点击空白同时取消选择并指定插入或粘贴位置。默认“框选：关”：按住空白拖动可连续定位竖光标，保留原音符选择；点击音符同时选中并把光标定位到实际点击拍位，再按 S 或点击“切割”即可分开。关闭框选时，拖音符中间仍移动音符，拖两端仍调整时长。

有快捷键的按钮会显示对应按键。用鼠标选中网页文字后，Ctrl+C（macOS 为 ⌘C）复制文字。编辑谱面并选中音符或歌词时，Ctrl+C 复制所选谱面内容；Ctrl+X 剪切；Ctrl+V 粘贴；Delete 删除；Ctrl+Z 撤销；Ctrl+Y 或 Ctrl+Shift+Z 重做；Ctrl+S 保存工程；Esc 清除选择；空格播放／暂停；S 在播放位置切开音符。

音符合并仅用于连续范围；不同音高会询问保留哪个音高，也可输入新的 MIDI 音高。有空拍时须主动选择填入空拍，夹有未选音符时拒绝合并。自由多选可批量替换音高、升降、复制或删除。

“时值检查与批量处理”按原音秒数定位短音／长音，选中音后仍保持可用。可选择全部结果、合并相邻同音短片段，或在播放位置切开长音；只按时长筛选不能证明音符错误。

十五、按歌词切分长音

如果一句唱得很快，却被识别成一个长音，而下方歌词已有正确的逐字或逐词时间：先采用歌词对应，点击长音（Ctrl 多选或框选可选择多个），再点顶部“按歌词切分”或右侧“按歌词切分此音”。查看预览中的字词、音高、原音起点和时长后，确认切分。取消预览不会修改谱子。

切分使用每个后续字词的原音起点，按当前对齐关系换算为最近的 1/16 拍；保留原长音的起止与音高，不重新运行识别模型。切出的音均标为待校对，可慢放逐字检查并改音高。歌词本身的原音时间不变，对应会更新到切出的音；Ctrl+Z 可一次恢复音符、歌词与选择。

只有带独立时间的字词才可确定边界。未定位的文字、单条整句文字不会被平均分配；过近或时间相同的边界会提示并跳过，文字保留。正常拖腔的一字多音无须使用此工具。

十六、编辑快捷键与开关

谱面工具条的“快捷键：开 / 关”可打开完整按键表与总开关，状态保存在本机；Ctrl+Alt+K 可随时切换（关闭后仍可用）。在文字输入框、参数输入框或弹窗中不会执行编辑快捷键。普通的输入、Tab、Enter 及 Ctrl/Shift 鼠标多选仍可用；关闭快捷键后，其他按键由浏览器按默认方式处理。

播放：空格播放/暂停；Alt+左右方向键退/进3秒；- 或 = 减/加0.05倍试听速度；R循环所选音符。
选择：左右方向键选前/后音；Ctrl+A全选音符，已选择歌词时全选歌词；Esc清除选择。
改谱：上下方向键升/降半音，Shift+上下方向键升/降八度；[ 或 ] 减/加单音1/16拍；S播放处切开，Shift+S在所选单音中点切开；M合并；L按歌词切分；V标为已校对；I打开插入工具。
通用：Ctrl+C/X/V复制/剪切/粘贴，Delete删除，Ctrl+Z撤销，Ctrl+Y或Ctrl+Shift+Z重做，Ctrl+S打开保存命名；?（Shift+/）打开快捷键面板。复制、切割、合并、删除会根据选择操作音符或歌词，音高和时长键仅用于音符。

持续按住方向键或时长键可连续调整；切割、合并、删除、保存和开关不会因长按连续执行。

十七、音符与歌词的联动编辑

谱面、歌词面板和点字词后的修改框都有“联动音符与歌词”开关，它们共用同一设置，默认关闭；确认对应准确后可手动开启，选择保存在本机。对应关系不仅用于显示：移动已关联的音符，会同步移动对应歌词；移动歌词也会联动对应音符。拉长、缩短或拖动左右边缘时只修改被操作的一方，不拉伸关联组。数值输入、拖动和歌词批量移动均支持。

一字多音、多字一音以及彼此相连的对应会构成一个联动组。操作前查看“当前对应组：几音、几个字词”；整个组一起移动，音符时值和歌词时长保持不变，其余音符与歌词不变。音高不随联动变化，对应ID不变。拖动时显示整组预览，松手后应用；如果与组外音符重叠、超出原音或压得过短，整组拒绝修改，可关掉联动后单独校准。

修改起止仍受1/16拍编辑网格限制，原音秒数与谱面拍位按现有对齐关系换算。取消拖动不修改，应用后可一次撤销并恢复两边。歌词识别预览未采用时不联动正式音符；先采用对应，再启用联动编辑。联动不触发模型识别，也不自动改音高。

组件安装与下载说明

基础版不需要首次下载环境。轻量版的分轨、Qwen 歌词、NVIDIA 和其他实验组件在组件管理中选择。扫描不会上传本机信息；复用只保存本机引用，原环境不升级、不复制。新下载写入程序目录，保留 CPU 环境，不修改显卡驱动或系统 pip 设置。

下载源有国内镜像和官方源，可切换优先顺序。模型和 CUDA 文件按固定版本、SHA-256 校验；连接失败会尝试备用源。网络中断可再次安装续传。各源可能临时不可用，安装详情会保留原因。

显卡组件中的 ONNX Runtime 同时提供 CPU 后端，检查通过后 CPU 卡片显示“随显卡组件可用”，无需重复下载；识别后端仍须通过原有一致性验证。安装按钮下方显示可安装状态或暂不可用原因。
正在复用的外部环境不可删除或移动。更换电脑后重新扫描、关联或补装组件。已保存谱子和手工歌词不依赖自动识别组件，始终可编辑。

加速与保存补充
高性能模式按模型分别选择设备。分轨和 CREPE 可以使用已验证的 NVIDIA 路径；Basic Pitch 显卡路径未通过一致性检查时使用 CPU，不表示整个任务都在 CPU 上运行。复用外部环境时会读取其模型与验证记录。任务完成后可在计算性能中查看实际设备与阶段耗时。
浏览器保存容量不足时，候选及替换前备份会转存程序的 exports 目录；恢复仍通过页面候选入口或恢复备份完成。请保留这些本机文件，迁移程序时一同带走 exports 与 runtime/audio-resources。候选文件是恢复记录，不用于打开工程；正式工程请使用保存工程。

十八、清理当前候选与原音

候选窗口只显示候选谱。点“收起”仍可恢复；点“删除候选”并确认后清除浏览器中的待采用候选，不删除正式谱或本机文件。
在“音频与识别”中点“卸载当前音频”，可释放当前原音和分轨；音符、歌词及候选保留。需要继续原音对照时重新导入音频。

试听倍速范围为 0.10–2.00 倍，主界面与候选窗口共用，可用滑条、数值或快捷键调节，导出仍使用工程原速度。


跨行拖放与混合选择
拖音符或歌词块主体可跨行移动，色块跟随鼠标；靠近谱面视口上下边缘会自动滚动。落点按 1/16 拍对齐，时长不变。松手在谱面外或按 Esc 取消。调整时长仍使用左右边缘，联动开启也只一起移动。
音符落点与其他音重叠时，先询问是否覆盖。确认仅替换重叠部分，其余片段保留；取消恢复原位，撤销一次恢复所有受影响内容。
同时框选音符和歌词后，工具条分别显示数量。复制、剪切、删除同时处理两种内容，粘贴后使用新的 ID，仅保留被一起复制的内部关联；粘贴位置点击空白指定，覆盖须明确开启。升降音只改变所选音符。歌词预览仍须明确采用，不会因编辑而自动采用。
“01 音频与识别”中并列提供“使用说明”和“开源致谢”，可直接打开对应内容。


十九、直观选音与连续写音符

音高选择默认提供 1 Do 至 7 Si 和 0 休止按钮，按音符所在拍位的调号解释。低一点 / 高一点调整半音，低一组 / 高一组调整八度；休止不能升降。原来的音名与 MIDI 下拉仍可在“专业音高选择”中打开。单音编辑立即生效；插入、批量替换、合并仍需各自确认。

右侧曲名下方打开“连续写音符”，先定起点、音组、升降号和时长，再点数字排队。点队列项可改音高、时长或删除；“继续添加”退出单项编辑。队列非空后起点固定，不会被播放或其他选择改变；取播放位置、取选中起点或输入拍位可主动调整。已有队列的实际音高不随起点改变。

整串试听只播放队列，不修改工程。“一次写入”最多 64 拍；遇到已有音符需确认覆盖，0 休止会在写入范围留空，不推走后续音符。范围外片段及歌词文字保留，失效对应留为未对应；写入可一次撤销。写入后起点前移，可继续输入下一串。

“高级：文本输入”保留原来的 1:1 2:0.5 #4:0.5 0:1 5:2 语法。切换工程、载入示例、采用新候选或导入音频时，若有未写入队列，会询问放弃并继续或取消。未写入内容不保存在工程文件中。

「歌曲区块」在「聆听与对照」上方，可直接展开整曲波形与列表。顶栏的「歌曲区块」可展开并定位到同一面板。长谱在谱面内部滚动，右栏独立滚动。

二十、框选整组编辑与实时拍位

开启框选后选中多个音符、歌词，直接拖动任一已选块即可整组跨行移动，无需关闭框选；在未选区域拖动仍创建新框选。Ctrl框选追加，Shift框选减选。多选拖动只移动、不改变长短。关闭联动时只移动明确选中的内容；开启联动时也移动其对应组。音符保持拍位间隔和时长，歌词保持原音秒数间隔和时长。越界整组拒绝；落点已有音符先询问覆盖，取消恢复原位。

顶部复制、剪切、粘贴、删除及相应快捷键作用于全部选择。音符与歌词混选后一起复制，点击目标空白再粘贴；只重建被一起复制的内部对应。右侧“覆盖目标音符与歌词”用于明确覆盖已有内容。整组移动、剪切、粘贴及删除均可一次撤销，恢复内容和选择。

调号与拍号一行的固定宽度区域实时显示光标的第几拍、所在行及行内拍位。界面从第1拍计数；例如第9拍是内部拍位8。点击定位、按住空白拖动及播放均更新该读数，不改变谱面时值。

F：开启／关闭框选。关闭总快捷键、编辑文字或打开弹窗时不触发；长按不会反复切换。

二十一、候选音符选择与回到试听起点

候选谱只用于选择方案和试听，不显示编辑用的左右拉伸手柄。点击音符会选中并定位到该音的原曲起点；若音符跨出当前显示范围，则从可见部分的起点开始。暂停时点“继续”或选择试听来源即可从该音播放；播放中点击会从该音继续当前来源。Enter或空格也可选择已聚焦的候选音符。

“回到试听起点”返回“本段试听位置”滑块选定的起点。正在播放时从该位置重播，暂停时只定位。

“上一页／下一页”按约 20 秒浏览当前段；短段只有一页。手动翻页时，试听与返回起点照旧；点播放栏的“恢复跟随”回到播放光标所在页，并恢复跟随。切段或调整试听滑块后，从新的试听起点对应页开始。

二十二、问题反馈与运行日志
顶部“问题反馈”可查看最近操作、耗时和错误。填写问题描述、复现步骤和预期结果，点“生成 / 更新报告预览”，检查或修改内容后下载 TXT，发给开发者。程序不会自动上传。
日志保存在本程序 runtime/logs，自动轮换，最多约 3 MB；可清空。不会读取音频、工程正文或歌词内容，不收集输入框文字；只有主动填写的反馈文字会进入报告。报告过滤个人路径和常见凭据，但发送前仍应检查错误文字和自己填写的内容。
暂时无法写入磁盘时，本次运行仍在内存中保留最近记录。突然关机可能丢失尚未写入的末尾日志。没有日志不能证明程序没有问题；反馈时请说明点击顺序，可自行另附不含隐私的截图。

二十三、谱子音色与内置乐器采样
聆听栏“谱子音色”提供原有、柔和、明亮、拨弦、笛声、弦乐等轻量合成音色。候选试听、单音试听、连续写入试听和 WAV 导出共用选择；原曲、分轨声音不变。选择保存在本机，不写入工程。
钢琴、尼龙弦吉他、小提琴、长笛采样随程序内置，无需在组件管理下载。使用时按需加载，可离线播放；逐音补偿响度并限制峰值。缺失、损坏或解码失败会提示并回到原有合成音色。采样来源及许可见 licenses/FluidR3-SAMPLES-NOTICE.txt。
采样音量与合成音共用聆听栏音量调节。试听与 WAV 导出均使用响度补偿；最终听感仍随乐器、音高和时长有所不同。

二十四、正式简谱排版
点击“导出乐谱 → 正式简谱排版”，左侧设置，右侧 A4 分页预览。此窗口读取工作区副本；候选需先采用。“重新读取工作区”主动载入最新内容。
默认按 1/4 拍整理节奏，可改为保留原时值、1/2、1/8 或 1/16 拍。整理前后可切换对照，并显示变化数量、最大拍位和原曲秒数偏移。重叠、零时长或无法表达的边界会提示改用更细精度，不自动删音。
可设置整曲或歌曲区块、曲名、导出文件名、拍号、记谱调号、速度、字号、小节密度、页边距、歌词和偏好降号。设置只影响导出副本；“保存排版设置到工程”保存这些设置，可撤销，音符和原曲对齐点不变。全谱调号覆盖仅改变记谱基准，不转调音高。
正式简谱显示数字、高低音点、升降号、减时线、附点、增时线、休止、小节线和延音线；密集小节自动换行，分页不裁断谱行。歌词按已有音符关联显示，未对应歌词在检查列表中保留。一字多音后续显示延续线。
打印 / 另存 PDF 打开系统打印，请选择另存为 PDF，建议关闭浏览器默认页眉页脚。下载整谱 SVG 输出相同的全部分页，纵向拼接为矢量图。原有 SVG、打印、MIDI、WAV、JSON 导出仍可使用。

二十五、五线谱模式与 GitHub
在工作区的“记谱模式”选“五线谱”。点音符会定位，暂停时可短试听；播放中会从点击位置继续。选中后可升降半音，或用常用时值和精确拍数修改音符。改时值固定起点，碰到下一音会提示，可用工作区原有撤销恢复。两种记谱视图共用工程、播放位置和选择，各自保留滚动位置。

MuScriptor large（可选实验组件）
在「音频与识别」选择自动识谱模式。传统识谱是默认模式，设备要求较低，可选 ROSVOT。安装 large 后可切换到 MuScriptor large，默认直接把所选原曲范围作为一段。勾选「分离人声与器乐并自动分段」后，按人声活动划分区段，耗时会增加。两种模式共用候选试听和工作区，切换只影响下次生成或单段重识别。Qwen 歌词仍可单独开启。
展开“MuScriptor 乐器轨”查看该输入所预测的 MIDI 乐器，有多份结果时用“识别输入”切换。点击乐器名称独听，再点一次退出独听；各轨可单独静音，也可恢复全轨。点击卷帘按原曲秒数定位，选择“原曲”或“MIDI”，再用独立的“播放／暂停”键试听。播放中切换模式或速度，会从当前秒数继续。原曲和 MIDI 自动匹配试听响度，独听或静音后按当前轨重新匹配，总音量仍用原有滑块调整。鼓组可听、可导出原始 MIDI。
试听合适后点“用此轨生成候选”。只替换当前段所选方案，其他段的选择保留。生成时在所选乐器轨内整理为单旋律，按 1/16 拍落位，并列出舍弃的复音与落在同一网格的音符。原始短音、连击、和弦可在卷帘核对。打开卷帘、切换轨道和转候选复用本机缓存。MuScriptor 候选通过卷帘的“识别输入”和乐器列表切换；传统候选保留“音轨”“识别方案”和“显示对照与备份”。
有对齐的人声分轨和 CREPE 时，人声候选会用 pYIN 和 CREPE 共同确认的音高在重叠音符中择音。已有候选可用“重新整理候选”试用，同一次 MuScriptor 结果可直接复用。音高证据不足时沿用普通候选。
翻页只改变显示范围；点“放入工作区修改”会先自动备份，再采用所有段落的当前选择。对选轨候选局部重识别时仍取同一乐器标签，新片段无可用音符则保留旧候选。
打开“编辑音符”并选择乐器轨。拖动音符可改时间与音高，拖右边缘可改时长，在空白处拖动可补音。点击音符后可删除，或按上下方向键改音高。支持撤销和重做。卷帘上的修改随暂存候选保存，点击“用此轨生成候选”才会将改过的音符转成简谱候选。原始多轨 MIDI 继续保留模型输出。

卷帘的「轨道纠错」可用已有的人声分轨找出时间和音高吻合的疑似错标。先试听并勾选，再应用。可能重复的音，以及伴奏分轨也出现同音高的音，默认不选。「合并轨道」把本段所选来源轨并到目标轨。在「编辑音符」里还可点选或框选后迁移一批音符。纠错可以撤销，生成候选前只影响卷帘。

MuScriptor 模式开启分轨时，人声段同时提供人声分离和原曲混音结果。相同资源及范围只分析一次，各段可复用。若要单独识别伴奏、吉他或贝斯等已分离音频，在卷帘的“识别输入”选择标为“待识别”的来源，再点击“识别此音轨”。只处理本段，支持取消。
候选名称标明四轨／六轨等实际输入来源；“显示对照与备份”可展开旧 Pitchy、原始候选和备份，默认仅收起不删除。旧版 Pitchy 与改进分音均为已停用的历史候选，只在展开对照或已选中时显示，不再生成新结果。有相应 MuScriptor 缓存时，可在乐器轨附近使用“从缓存重新整理”和“导出原始多轨 MIDI”。
普通模式使用 CPU，高性能模式可尝试 NVIDIA；显卡失败回退同一 large 模型的 CPU，不自动替换成 medium/small。自动模式在 CUDA 优先 FP16，CPU 使用 FP32；也可主动选择精度。large 权重约5.47 GB，8GB显卡仍可能显存不足，实际速度与效果需短片段听审。
权重仅限非商用（CC BY-NC 4.0 及附加条款），需要在 Hugging Face 接受 large 仓库条款。组件管理可指定已有权重文件或临时使用只读令牌；令牌不要发给他人，不保存到工程。安装后可离线推理。具体说明见 docs/MuScriptor组件.md。


【MuScriptor 异常检查】
在候选谱里选择一份 MuScriptor 方案，点「检查当前候选」。程序依据已有原始 MIDI 和本机音频标出疑似漏音、疑似轨名错标或证据不足的区间。点击时间段可循环试听原曲或候选谱。疑似漏音可手动「重识别这段」，送入模型的音频带少量前后文，标记范围的结果会加入本段备选。可对比两个版本，再决定采用哪一份。

【MuScriptor large 计算精度】
在“音频与识别”选择 MuScriptor large 后，可选自动、FP16、BF16、FP32。自动在高性能 CUDA 模式使用 FP16；CPU 一律 FP32。复用同一 large 权重，无需重新下载。音频特征保持 FP32。结果可能随精度变化，FP32 可作对照，不能保证识别准确率相同。数值异常时回退 FP32，显卡不可用或显存不足回退 CPU；计算明细显示各实际音轨的设备、精度与缓存情况，警告说明回退原因。精度设置只保存在本机，修改后下次任务生效。


【Windows 安装包与更新】
新版提供精简版和基础版。精简版仅提供编辑、试听、MIDI 导入与谱子导出；基础版增加离线扒谱、Python CPU 环境与四／六轨分轨。小型采样音色内置。选装组件默认不勾选。
安装向导可经同意检查已有环境，安装后在本机组件页面确认复用或下载。旧程序先保存工程，再安装到新目录迁移。卸载默认保留 runtime、模型、配置与个人文件。
版本与更新支持自动/国内/GitHub 来源；国内入口未配置时使用 GitHub。首次签名清单未发布时显示尚未开放，不表示已是最新。

候选采用与原谱保护
点击“放入工作区修改”会先备份，再用完整候选覆盖当前工作区。原有音符、歌词和人工修改可能被覆盖，包括浏览页以外的内容。分段候选会采用各段当前选中的方案；候选中的空白按原样保留。
若需要把整个识别区段中的空白也写入，请选择“完整识别区段”；只有明确选择“整份替换工作区”才会整谱替换。采用前显示范围及音数，备份失败时不修改；采用后可撤销或从“恢复备份”找回原谱。新曲仍采用完整候选。


27. 工作区规范简谱预览
在顶部导航正中点击“简谱预览”，打开只读悬浮窗。拖动标题移动，拖动右下角缩放；双击标题或点击最大化可放大，再次操作还原。关闭再打开保留本次窗口位置和大小。
预览按小节、分页显示规范简谱，包含歌词及工程已有的演唱记号。音符、时值和歌词在原工作区修改，打开的预览自动刷新。默认保留原时值；不规则边界无法排版时可选择整理精度，设置仅作用于预览及导出副本。
成品改谱：顶部“改谱台”在新标签直接打开工作区当前显示的整份谱和歌词。需要一起带上原音和对齐点时，使用“导出乐谱 → 送到改谱台”，勾选原音后点击“在改谱台打开”。未能直接打开时会下载 .scoredesk 工程，可在改谱台手动打开。后续修改和成品导出在改谱台完成。

点击“导出到 Dolce（MusicXML）”下载乐谱文件，在 Dolce 中打开后继续改谱。文件包含实际音高、拍号、调号、速度、节奏、已关联歌词和已有演唱记号。跨小节持续音以延音线连接，一字多音在起始音显示歌词。
MusicXML 用于乐谱交接，NoteMender 工程继续用 JSON 保存。Dolce 中的编辑结果保存在 Dolce 中。
SVG 导出全部谱页；打印 / PDF 使用系统打印窗口。字体与排版资源已内置，可离线使用。五线谱工作区可以切换谱号、缩放、导出 MusicXML 和打印／另存 PDF。谱号默认根据全曲音域选择。弱起读取工程已保存的排版设置，首次打开旧工程按完整首小节显示。顶部 GitHub 按钮打开项目源码、更新与反馈入口。

28. 自动整理成谱（试用）
在“简谱预览”点击“自动整理成谱”，再用“对照”切换原时值、自动整理和按精度整理。正式简谱排版也提供同名按钮及按拍分组。整理只影响预览和导出副本，不修改工作区音符、歌词或原曲对齐点。
自动整理在每个边界最多移动 ⅛ 拍的范围内，优先选择易读的二进制节奏，保留音符数量及先后次序。短音不会自动删除。无法表达、重叠等问题会阻止排版并提示调整，不能保证未经校对即可作为最终乐谱。
“合并 ≤⅛ 拍音间空隙”默认关闭，仅用于自动整理。开启后将前一音延长到后一音开头，填平不超过 ⅛ 拍的细碎间隙；明确写入的休止符与较大间隙保留。此额外延长也计入最大调整显示，呼吸间隙请人工核对。
“首小节拍数”用于弱起。0 表示完整小节；若歌曲第一小节只有一拍，填 1。程序按该首小节长度重新分小节，后面使用完整拍号。这里的拍与工作区一致，按四分音符计算，6/8 完整小节为 3 拍。输入必须小于完整小节。
按拍分组将短音按拍断开减时线；6/8 按附点四分音符分为两组，跨拍的偏拍长音可拆开并用延音线连接。原音符 ID 与总时长保留。MusicXML 导出使用相同的整理结果及弱起长度。
这一整理选项不自动分析音频强拍，也不自动判断弱起。先确认速度与第一小节位置，再比较整理前后，必要时回到工作区修正识别误差。切换方案不会替你合并重复音、删除装饰音或推断主旋律。

29. 小节线与手动标记
简谱预览沿用工程拍号和弱起。原曲自动划小节（Beat This!）、手打拍子和工作区小节标记目前暂停开放。

手动标记：在聆听栏点击「加标记」或按 B，记录当前播放位置。展开「标记」可定位、改名、移动或删除，并任选两个标记作为 A、B 循环复听。「用作写入拍位」按 1/16 拍网格填入插音和粘贴位置。有原曲的标记固定在原曲时间，纯谱工程按拍位保存。标记随工程保存，可撤销。
