# 五线谱工作区

在工作区的「记谱模式」选「五线谱」。点音符定位，暂停时短试听，播放中从该拍继续。音高按钮每次移动半音。时值可用常用选项或输入拍数。修改时值保留起点，占到下一音的位置时会提示。撤销和重做与简谱共用。

默认按整首旋律的加线数量选择高音或低音谱号，也可以手动选择。五线谱有独立的缩放和滚动位置。「导出 MusicXML」可把乐谱交给支持该格式的排谱软件，「打印／PDF」使用系统的 A4 打印窗口。

## 数据与记谱

- 工作区仍以工程里的单旋律为准。VexFlow 绘制 SVG。谱面、中间数据和 MusicXML 保留每个原音的音高、开始拍和总时值。
- 按当前拍号和段落调号排谱。弱起读取工程已保存的正式简谱排版设置。工程缺少弱起设置时，首小节显示为完整小节。
- 延音线连接拆开的持续音。点延音的不同部分可以分别定位。改变音高或时值针对原音，关联歌词和已有演唱记号随原音保留。
- 支持 2/4、3/4、4/4、6/8 和现有 1/16 拍编辑网格。复杂排版和多声部编辑可交给外部排谱软件。
