# 五线谱模式：当前入口与后续设计

当前版本提供模式选择和独立筹备页。简谱工程仍是唯一正式音符来源；五线谱尚不绘制、不编辑、不导出，切换入口不会转换或丢失工程。

欢迎在 GitHub Issues 提交谱面样例、制作方法及交互建议：https://github.com/goldotto/NoteMender/issues

## 可复用的数据

- 主旋律音符：稳定 ID、MIDI 音高、起始拍与时长；四分音符为一拍。
- 歌词：原曲秒数范围、关联音符 ID、人工确认状态；允许一字多音、多字一音。
- 工程：拍号、速度、段落调号及原曲时间映射。
- 正式简谱排版：独立副本、节奏整理差异、小节拆分、整行分页。

## 需要讨论的制作规则

1. 谱号和音域：高音谱号是否足够，何时切换低音谱号。
2. 调式和音名：目前“1=”只是简谱基准，不能直接当成已确定的大调或小调；需明确调性输入和升降号拼写。
3. 节奏：符干方向、连梁分组、附点、休止、跨拍拆分、延音线和弱起。
4. 操作：选择与播放定位、拖动改音高与起点、时值修改、撤销及歌词对应。
5. 输出：跨行布局、歌词空白、换页、可打印文件及后续 MusicXML 交换。

建议后续从单声部、固定拍号、有人工核对的短谱开始。展示、编辑和导出应共用音符来源与记谱规则，避免三个界面出现不同结果。新增规则需有明确样例及预期谱面后再实现。
