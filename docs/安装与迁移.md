# 安装与迁移

## 选择版本

- 精简版：人工编辑、试听、MIDI 导入和谱子导出。没有 Python、扒谱模型或分轨模型。
- 基础版：精简版全部功能，加离线扒谱、Python CPU 音频环境、四轨及六轨 Demucs。无需第一次下载这些组件。
- Qwen 歌词、NVIDIA、ROSVOT、MuScriptor 为选装，默认不选；四种小型采样音色内置。MuScriptor 权重需自行接受官方条款，不随包转存。

## 安装

运行 Windows x64 EXE，选择目录和快捷方式，再选择需要的选装组件。默认不扫描电脑；可允许检查常用环境，或只指定一个目录。检测结果需点击“校验并复用”确认，不修改外部环境。

程序文件由安装向导安装；选装组件阶段打开本机“组件管理与安装”页面，与工作台共用同一套检查、进度、取消和下载逻辑。确认已选功能后点击“安装所选组件”。取消、重试或跳过不影响已安装编辑器。可随时从顶部“组件管理”补装。

安装器拒绝覆盖已经包含程序的目录。已安装新版的日常升级使用“版本与更新”；切换到基础版可在组件管理补装，也可在新目录安装基础 EXE 后迁移。安装器默认不结束后台服务；保存工作并退出服务后再卸载。

## 旧版迁移

1. 在旧版保存正式工程；候选、歌词预览和未提交连续输入先处理。工程引用音频不等于音频已嵌入，另行保留原音文件。
2. 保留旧目录，安装到新的空目录。打开原工程，重新关联缺失音频。浏览器来源改变时，自动保存不会自动跨来源出现，使用工程文件迁移。
3. 组件管理主动指定旧 NoteMender 或 Python 目录，校验后复用。外部目录必须继续保留。个人工程、候选和音频不通过复制整个 runtime 盲目迁移。
4. 新版试用无误再决定旧目录去留；不要先删除唯一模型和私人资源。

## 卸载和更新

卸载默认保留 runtime（含已下载模型、解释器、组件配置、更新备份）、个人工程、exports 和未知文件。卸载不是清理磁盘工具；不自动删除私人资料。需要清理时先确认备份，再自行处理明确不用的目录。

新安装包携带对应程序文件的签名安装凭据。程序更新只下载程序文件，不补装精简版缺少的组件，不覆盖模型、插件或个人配置。源代码目录、修改过的程序或没有有效安装凭据的旧版，不支持原地覆盖更新，按上述方式迁移。

## 国内下载

国内入口未配置前使用 GitHub。未来 Gitee 首页会提供两个版本说明与下载按钮；较大的基础版可能通过国内网盘提供完整 EXE。网盘是否要求登录、客户端及限速须在页面说明；分享链接不是自动更新直链。

首次对外发布签名清单前，自动更新可能显示“尚未开放”。网络失败与限流不代表“已是最新”。
