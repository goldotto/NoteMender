# 识别方案说明

## 先看音轨，再看方案

音轨选人声、钢琴、吉他、贝斯或其他器乐；方案决定怎样从这条音轨获得主旋律。Demucs 负责分轨，不直接识别音符。
下列适用情况是根据算法特点给出的使用建议，歌曲效果仍须试听比较。

| 候选名称 | 用什么 | 如何使用 |
| --- | --- | --- |
| 自动首选 | 按段使用 Basic Pitch 与单音音高证据，执行人声融合或器乐旋律筛选 | 首先试听。歌词只附加对应，默认不按字词时间改分音；ROSVOT 不决定首选。 |
| Basic Pitch 连续旋律 | Basic Pitch 多音符模型 + 程序的单旋律筛选 | 器乐轨、人声轨均可比较，连续性规则可能抹掉真实大跳。 |
| Pitchy / Pitchy 连续音高分音 | McLeod 音高算法 + 程序分音 | 清晰单音人声、哼唱或独奏；混音和和弦可能干扰。它不是训练模型。 |
| 密集器乐追踪 | Basic Pitch 多音候选 + 连续旋律路径 | 多声部器乐；需要确认是否跟到了想要的声部。 |
| Basic Pitch 无连续性约束 | Basic Pitch 候选 + 不惩罚音高大跳的旋律筛选 | 检查大跳被删的问题，也可能跳到伴奏声部。仍不是全部模型原始输出。 |
| 原始候选旋律（含短音） | Basic Pitch 原始候选含短音，再筛选单旋律 | 检查快音、装饰音遗漏；短音也可能是伪音。 |
| pYIN / pyin | pYIN 概率音高跟踪 + 程序分音 | 清晰单音人声或独奏的实验对照，不适合和弦混音。 |
| CREPE / crepe | CREPE tiny 模型（torchcrepe）+ 程序分音 | 人声或单音独奏的音准对照，需可选环境；不识别歌词。 |
| 歌词边界辅助分音（备选） | 原声学音符 + Qwen 字词时间 + 起音／停顿证据 | 比较重复同音、拖腔末尾；只有人工选用才进入本段正式候选。 |
| ROSVOT 字词条件分音（辅助） | ROSVOT + RMVPE，模型输入 Qwen 字词时间 | 比较换字、重新起唱；已经受歌词边界影响，可能漏音或多音。 |
| ROSVOT 字词对齐修整（辅助） | 上述条件分音再按字词边界修整 | 更重视文字对应，容易过度切音／并音，仅作辅助。 |
| 演唱精细分音 · ROSVOT | ROSVOT + RMVPE + RWBD 自动边界 | 没有 Qwen 时间输入时的演唱候选；公开检查点以中文演唱训练，英日韩需分别听审。 |
| 原分音 / 原首选 / 先前 | 保留的先前谱面版本 | 对照及恢复；具体模型取决于当时的识别设置。 |

## 音频与识别中的设置

- **本机扒谱方式**：自动按段选择；Basic Pitch 手动指定；Pitchy 手动指定。后两者不是曲风分类。
- **现版 · 默认基线**：现有 Basic Pitch／Pitchy 和旧处理规则，便于稳定比较。
- **改进规则 · 实验**：模型仍是 Basic Pitch／Pitchy，改变短音、重复音、能量、融合和旋律筛选规则；不保证一定更准确。
- **改进规则 + pYIN**：增加 pYIN 单音音高证据。
- **改进规则 + CREPE**：增加 CREPE tiny 单音音高证据。
- **计算性能**：改变运行设备和后端，不指定旋律声部。开启高性能不会自动勾选 ROSVOT。
- **ROSVOT 额外候选**：主动勾选后才计算；歌词对齐结果不自动替换首选。

“按歌词重新分音本句”属于主动操作：显示有声学证据的辅助分音预览，原分音留作备选；仍需确认才替换工程。
