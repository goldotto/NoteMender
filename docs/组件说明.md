# 组件管理与安装

推荐基础离线版（约 0.81 GB），内置 CPU 音频环境和四／六轨 Demucs 模型，解压即可扒谱、分轨、试听和编辑。轻量版约 65 MB，提供 Node.js、Python 基础解释器和浏览器识别；其他组件按需添加。

Qwen 歌词、NVIDIA 显卡和 ROSVOT 实验组件默认不勾选。不安装 Qwen 也能手工输入、编辑和关联歌词。

## 图形安装与复用

1. 双击 `Start-NoteMender.cmd`，首次显示安装界面，先选择“允许扫描已有环境”或“暂不扫描”。扫描只检查常用 Python、注册信息和模型缓存，不遍历整块硬盘，也不上传结果。
2. 可展开“指定已有程序或环境目录”，检查其他安装位置。找到后点“校验并复用”，验证实际依赖、兼容版本和模型哈希，通过后保存本机引用。原环境不复制、不升级；不要删除或移动正在复用的文件。
3. 勾选需要的新组件，点“安装所选组件”。相关依赖顺序补齐，已经可用的组件跳过；显示阶段、进度、磁盘空间和详情。可取消后重试续传。新增组件只写入本程序目录的 `runtime/` 或项目虚拟环境。
4. 点击“进入工作台”。以后启动直接进工作台，顶部“组件管理”、`Manage-Components.cmd` 或 `Download-Components.cmd` 都可再次打开安装界面。

组件缺失时对应自动按钮变灰，悬停说明用途与下载入口；手工编辑和已有工程继续可用。组件引用仅保存在本机，不写入工程 JSON。

## 组件用途与下载源

四轨负责人声、贝斯、鼓及其他器乐；六轨增加吉他／钢琴。Qwen3-ASR 0.6B 与 ForcedAligner 用于歌词转写和原音时间对齐。显卡组件为 PyTorch 2.7.1+cu128 与 ONNX Runtime GPU 1.22.0。ROSVOT 作为额外人声候选；原生 CPU 推理也可单独安装。

可选择“中国大陆源优先”或“官方源优先”。Python 依赖使用清华、阿里云、PyPI；CUDA 安装文件使用交大镜像和 PyTorch 官方；Qwen 使用 ModelScope、HF-Mirror、Hugging Face。各平台使用对应的固定版本编号，模型及 CUDA 文件按固定 SHA-256 校验，失败后切换源。

取消或断线保留未完成下载供重试，不标记为就绪。各源可能临时不可用，安装详情显示原因。安装不修改系统 pip 设置或显卡驱动。程序目录应可写，建议放在普通文件夹。

需要 NVIDIA CUDA 驱动才能使用显卡计算。界面会显示各阶段实际设备及回退原因；使用高性能不改变音符编辑精度。各模型按需安装，首次下载可能较大。

## 原生后端一致性检查

原生 Basic Pitch 后端在安装后还需要与浏览器基线比较，未通过不会启用。为公开代码提供了基于合成音阶的检查输入：

```text
node scripts/create-compute-fixtures.mjs
node scripts/benchmark-compute.mjs
node scripts/benchmark-compute.mjs --cuda
node scripts/benchmark-compute.mjs --gpu-cpu
```

输入仅有 5 秒合成音阶；不带 --seconds 的命令才会写入后端通过状态，带此参数的快速检查不会启用后端。CPU 只需运行第一项基线检查；GPU 需运行 CUDA 与 GPU 环境的 CPU 回退检查。依次运行，不要同时开启多份检查。合成片段只检验后端一致性，不代表真实歌曲识别质量。

Demucs / CREPE 的显卡检查可按需要运行：

```text
node scripts/qualify-torch.mjs demucs
node scripts/qualify-torch.mjs crepe
```

`requirements-experimental.txt` 列出 CREPE 等实验分析依赖；需安装到项目 Python 环境。安装状态、通过状态、设备是否可用是不同事项，页面给出实际结果。

## 迁移

编辑内容请另存 JSON；音频资源在 `runtime/audio-resources/`。换设备可以复制音频资源，或重新导入原音。标准离线版使用包内解释器，可完整复制程序目录到另一台 Windows x64 设备；源码版的 Python 虚拟环境不保证跨路径迁移，可重新运行安装入口。
