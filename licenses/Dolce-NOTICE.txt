NoteMender bundles selected browser engraving modules in public/vendor/dolce.js.
The upstream renderer is bundled without source modifications. NoteMender's
adapter projects its own note identities, pitches, lyrics and performance
markings into a disposable Dolce document. NoteMender remains the editor and
project authority. No remote editor, OCR model or online service is required.

Rebuilding the checked-in bundle is an explicit maintainer action. Check out
the pinned upstream commit, install NoteMender's normal build dependencies,
then run node scripts/build-dolce.mjs <path-to-pinned-checkout> from the project
root. Normal offline builds use the checked-in bundle and require no checkout.
Review upstream changes and licenses before changing the pinned revision.

Dolce was selected for its browser SVG engraving, note identity mapping,
numbered notation, lyrics and performance marks. Sparks NMN was also reviewed
(Apache-2.0, https://github.com/yezhiyi9670/sparks-notation-1). Dolce's selected
renderer fitted the existing note-ID based editing flow. jianpu-ly was reviewed
as a LilyPond-backed offline publishing tool rather than a browser editor.
These alternatives are not bundled.
